# My 90 Days — Happy Thoughts PWA

This is a mobile-friendly Progressive Web App (PWA).

## To install on Android
1. Put these files on any HTTPS website/hosting service.
2. Open the website in Chrome.
3. Tap **Install** when the app offers it, or Chrome menu → **Add to Home screen / Install app**.
4. The tracker stores entries locally in the browser.

## Important
The app is offline-friendly after it has been loaded once, but browser storage can be cleared. Use the built-in Backup My Data option regularly.
